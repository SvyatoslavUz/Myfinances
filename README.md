# 📱 Мои Финансы (Finance Tracker)

Удобное кроссплатформенное мобильное приложение для учета личных финансов, контроля доходов и расходов с поддержкой мультивалютности и детальной аналитики.

---

## ✨ Основные возможности

* **📊 Учет доходов и расходов:** Быстрое добавление операций с выбором категорий (Зарплата, Продукты, Долги, Вредные привычки и др.).
* **📅 Гибкая фильтрация по периодам:** Просмотр баланса и трат за *Сегодня*, *Эту неделю*, *Этот месяц* или за всё время.
* **📈 Наглядная статистика:** Круговые диаграммы, аналитика структуры расходов и история всех транзакций.
* **🌍 Мультивалютность:** Автоматическое форматирование баланса, списков операций и графиков под выбранную валюту:
  * 🇺🇸 Доллар США (`USD`, `$`)
  * 🇪🇺 Евро (`EUR`, `€`)
  * 🇺🇿 Узбекский сум (`UZS`, `сўм`)
  * 🇰🇿 Казахстанский тенге (`KZT`, `₸`)
  * 🇨🇳 Китайский юань (`CNY`, `¥`)
  * 🇷🇺 Российский рубль (`RUB`, `₽`)
* **🌐 Двуязычный интерфейс:** Полная локализация интерфейса (**Русский** / **English**).
* **⚙️ Панель настроек (Settings Modal):** Быстрое переключение языка и валюты с сохранением параметров на устройстве.
* **🌙 Современный UI:** Темная тема с акцентными цветами для комфортного использования.

---

## 🛠 Стек технологий

* **Frontend / Mobile:** React Native / Expo 
* **Иконки & Стилизация:** Lucide Icons / Tailwind CSS
* **Хранилище данных:** LocalStorage / Async Storage
